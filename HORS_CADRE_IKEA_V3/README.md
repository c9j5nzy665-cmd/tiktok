# HORS CADRE — Effet IKEA V3 (images réelles)

Ce projet est prêt à être ouvert dans Codex avec accès Internet.

## Objectif
Refaire le Reel « Effet IKEA » avec une majorité de vrais visuels stock, en conservant la voix ElevenLabs et les sous-titres existants.

## Rendu final
Commande unique :

```bash
chmod +x render.sh
./render.sh
```

Le script télécharge les médias réels listés dans `SOURCES.md`, crée les 8 scènes en 1080×1920 / 30 fps, ajoute la voix et brûle les sous-titres.

Fichier produit :
`HORS_CADRE_EFFET_IKEA_MASTER_V3_REEL_IMAGES_REELLES.mp4`
